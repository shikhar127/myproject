Calendar-aware wake-ups

Import your calendar and WakeWork finds each day's first meeting. If it starts before your threshold (10:00), it suggests a wake time = meeting − getting-ready time − commute (commute is skipped on WFH days).

Import .ics file

Google Calendar → Settings → Import & export → Export. Outlook/Apple Calendar exports work too. Parsed entirely on this device — nothing is uploaded.

Production plan

The native app will read the device calendar directly (Android Calendar Provider / iOS EventKit) — no export step, auto-refresh nightly. A web companion would use Google Calendar OAuth (calendar.readonly). Details in ALARM-APP.md.
